# Launch film · 15 s · 16:9

Built from [`docs/shotlist.md`](../docs/shotlist.md) in the grammar of [`docs/style_guide.md`](../docs/style_guide.md).

- **Output:** `out/propiedad-conecta-15s.mp4` (1920 × 1080, 60 fps, 900 frames, H.264 + AAC 256 kbps) and `out/propiedad-conecta-15s-contact-sheet.jpg` (one frame every 0.5 s).
- **Preview:** serve the repo root (`npx http-server .`) and open `/video/index.html`. Click to pause; `?t=6.5` shows one still.

## Rebuild

```sh
python3 video/prep.py          # crops the real screenshots into video/assets/ (x3 Lanczos, nothing redrawn)
python3 video/music/compose.py # synthesises the original soundtrack → video/music/soundtrack.wav (needs scipy, pyloudnorm)
node video/render.mjs          # renders every frame with Playwright, pipes it to ffmpeg and muxes the soundtrack
node video/render.mjs --stills 1,6.5,14.9   # stills only, into video/out/stills/
```

`index.html` draws every frame as a pure function of time (`draw(t)`), so a render is deterministic.

## Sources

- Music: original, generated by `music/compose.py` (150 BPM half-time, D major, −14 LUFS). No samples or licensed audio.

- UI: four real 1440 × 900 captures in `anuncios/reel-publica-tu-busqueda/animatic/capturas/originales-1440/` (form empty, top filled, Características filled, contact + button). `prep.py` documents the crop coordinates; replace the files and re-run it if the site changes.
- Logo: `anuncios/reel-publica-tu-busqueda/marca/` at 45 % of the file (≤ 100 %, uniform), on ivory only, parts never animated.
- Font: Outfit (OFL), from `anuncios/reel-publica-tu-busqueda/animatic/fuentes/`.
